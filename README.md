# clock

このコードは今の日本時間を正確にリアルタイムで表示するコードです。
皆さんは時間を確認したい時に、秒数を知りたい時ありますよね 
そんな時にこのようなコードを使えば生活に役立てることができます。

## インストール方法

```
$ git clone https://github.com/puusan13/clock.git
$ cd clock
```

## 使い方

実行すると、Ctrl+C で停止するまで 1 秒ごとに現在の日本時間を出力します。

```
$ ./clock
2026-11-24 23:00:01
2026-11-24 23:00:02
2026-11-24 23:00:03
```

引数を指定した場合は、標準エラー出力にメッセージを出力して終了ステータス 1 で終了します。

## テスト

以下のコマンドで動作テストを実行できます。

```
$ ./test.bash
```

## 動作環境

* Ubuntu 24.04.1 LTS
* Python 3.12 / 3.13
